# NaturalHealing.ai — AI Coach prototype

Standalone public design demo. All patient identities, reports, camera previews and replies are fictional. No API key, real patient information, backend connection or production website code is included.

Open `prototype.html` to interact, or `review.html` for screens and flowchart. Uploads, photo capture and saves are simulated.

GitHub Pages serves the main branch root. Production naturalhealing.ai stays separate.
